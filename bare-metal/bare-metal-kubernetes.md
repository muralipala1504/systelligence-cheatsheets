## 1. Pre-Installation System Preparation
```bash
# Disable swap permanently
swapoff -a
sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab

# Load kernel modules
modprobe overlay
modprobe br_netfilter
# Make persistent in /etc/modules-load.d/k8s.conf

# Set sysctl parameters
cat <<EOF > /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables = 1
net.ipv4.ip_forward = 1
EOF
sysctl --system

# Add Kubernetes repo (not in default RHEL repos)
cat <<EOF > /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.30/rpm/
enabled=1
gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.30/rpm/repodata/repomd.xml.key
EOF

# Install tools
dnf install -y kubelet kubeadm kubectl
systemctl enable --now kubelet

2. Container Runtime (containerd)

# Install from Docker repo
dnf config-manager --add-repo https://download.docker.com/linux/rhel/docker-ce.repo
dnf install -y containerd.io

# Generate default config
containerd config default > /etc/containerd/config.toml

# CRITICAL FOR RHEL 10 (cgroup v2)
sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
systemctl enable --now containerd

3. kubeadm init & Cluster Bootstrap

# Initialize the control plane
kubeadm init --pod-network-cidr=192.168.0.0/16 --apiserver-advertise-address=<CONTROL_PLANE_IP>

# Configure kubectl for the current user
mkdir -p $HOME/.kube
cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config

4. Calico CNI Installation

# Install the operator
kubectl create -f https://raw.githubusercontent.com/projectcalico/calico/v3.28.0/manifests/tigera-operator.yaml
kubectl create -f https://raw.githubusercontent.com/projectcalico/calico/v3.28.0/manifests/custom-resources.yaml

# Watch nodes change to Ready
kubectl get nodes -w

5. Adding Worker Nodes

# Run the join command generated by kubeadm init on the worker
kubeadm join <CONTROL_PLANE_IP>:6443 --token <TOKEN> --discovery-token-ca-cert-hash sha256:<HASH>

# Verify from control plane
kubectl get nodes

6. MetalLB (Load Balancer for Bare Metal)

kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/v0.14.8/config/manifests/metallb-native.yaml

Create an IPAddressPool and L2Advertisement (YAML) to assign local IPs to LoadBalancer services.

7. Persistent Storage (Local Path Provisioner)

kubectl apply -f https://raw.githubusercontent.com/rancher/local-path-provisioner/v0.0.28/deploy/local-path-storage.yaml
kubectl patch storageclass local-path -p '{"metadata": {"annotations":{"storageclass.kubernetes.io/is-default-class":"true"}}}'

8. SELinux & GPU
SELinux: Keep it Enforcing. If you use hostPath volumes, apply the correct context: semanage fcontext -a -t container_file_t "/path/to/volume(/.*)?"

GPU: Install NVIDIA drivers on the OS, then deploy the NVIDIA GPU Operator (DaemonSet) to pass GPUs to pods.
